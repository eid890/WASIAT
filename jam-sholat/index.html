URL Sinkronisasi (Google Apps Script)

Isi URL ini agar semua pengaturan (jadwal, banner/video, pengumuman, identitas, dll) otomatis tersinkron ke semua perangkat. Penting: mengisi kolom ini saja hanya berlaku di perangkat/browser ini. Supaya berlaku otomatis di SEMUA perangkat sejak awal dibuka (tanpa perlu diatur satu-satu), klik "Unduh config.json" di bawah lalu upload file itu ke GitHub (timpa yang lama).

Akses Imam — URL Web App WASIAT

Tombol "🚫 Lapor Berhalangan" kini tampil di semua perangkat, tapi baru bisa dipakai setelah imam masuk dengan akun WASIAT-nya (peran Imam Masjid). Jadi tidak perlu lagi link khusus yang mudah hilang kalau cache dibersihkan atau ganti HP.

Alamat ini sama dengan yang dipakai aplikasi WASIAT (WEBAPP_URL di index.html-nya) — bukan URL Sinkronisasi di atas. Admin perlu menambahkan peran "Imam Masjid" untuk akun imam di menu RoleAkses WASIAT.

Layar Ini Menampilkan Untuk

Pengaturan ini HANYA berlaku di perangkat/layar ini sendiri, tidak ikut tersinkron ke layar lain. Kalau dipasang di dua lokasi (masjid putra dan putri), atur masing-masing layar sesuai lokasinya. Banner/pengumuman/data santri yang ditandai "Semua" tetap tampil di kedua layar; yang ditandai khusus Putra/Putri hanya tampil di layar yang sesuai.
